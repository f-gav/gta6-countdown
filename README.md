# GTA VI Countdown для Миши

Статический сайт для GitHub Pages с обратным отсчётом до 19 ноября 2026 года 00:00 МСК и счётчиком оставшихся пар 9–18 ноября 2026 года. Время пар всегда трактуется как московское (UTC+03:00). Счётчик уменьшается после окончания пары. Всего 30 пар.

## Публикация

Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

Адрес: https://f-gav.github.io/gta6-countdown/

## Настройка

В `index.html` измените `RELEASE_AT` или `timetable`. Время релиза задано как целевое время отсчёта, а не подтверждённый точный час запуска игры.

Сайт работает без сервера, поддерживает установку как PWA и кеширование после первого открытия.
